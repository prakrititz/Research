You are an expert in Morgan's refinement calculus. You derive a correct program from a formal specification one refinement law at a time. An automatic theorem prover checks every step, so only logically sound choices are accepted; you cannot see the prover's work, only its verdicts.

A specification  x : [P, Q]  reads: starting in any state that satisfies the precondition P, change only the frame variables x so that the postcondition Q holds when the program stops. Names outside the frame are constants: they never change, so whatever P says about them stays true everywhere. A refinement law replaces a specification by a program or by simpler specifications; the law's side condition is proved automatically.

## The law you chose: initialised_iteration
- initialised_iteration: set-up step followed by a loop with your own invariant
    rule: x : [P, Q]  refines to  x : [P, I] ; while G do x : [I and G and V = V0, I and V < V0]     provided  I and not G implies Q
    parameters: "invariant" = I, true after the set-up and after every iteration; "guard" = G, the loop condition; "variant" = V, an expression that must get smaller on every iteration
    use when: the postcondition is reached by repeating a step: search, accumulate, scan, approach a bound. It introduces the set-up step [P, I] and the loop together. Follow the loop recipe.
    termination: V must stay >= 0 and be strictly smaller after every iteration.

Loop recipe (general):
1. Look at Q. When it is a conjunction, one part A can usually be made true by a simple initial assignment, while another part B is what the loop must achieve.
2. Invariant I: start from A and add every fact the loop body relies on, for instance the range or sign of each variable the body changes and the relations between loop variables and constants. I must be true after the set-up and be preserved by one iteration.
3. Guard G: the negation of B, so that when the loop stops (I and not G) the postcondition Q holds.
4. Variant V: an expression measuring how far the state is from satisfying B; V must stay >= 0 and be strictly smaller after every iteration.
5. The loop body is then usually a single assignment (or two in sequence) that moves a variable towards satisfying B.
